ISTARI — The Wizard's Quest
===========================
A self-contained browser platform game prototype.

PLAY
- Open index.html in a modern browser.
- Desktop: A/D or left/right arrows to move, Space/Up to jump, X to cast wizard-fire, C for a magic shield.
- Android: use the on-screen buttons.
- Collect glowing runes, defeat goblins, manage health and mana, and reach the banner at the end of the level.

PUBLISH FREE WITH GITHUB PAGES (Android-friendly)
1. Download and extract ISTARI-browser-game.zip on your phone.
2. Open your GitHub Pages repository in GitHub Mobile or Brave.
3. In the repository root, choose Add file / Upload files.
4. Upload index.html from this ZIP. If this repository is currently used for another app, back up its current index.html first or use a separate repository.
5. Commit the change, then open your GitHub Pages URL.
6. If the old page appears, refresh or try a private tab; GitHub Pages can take a short time to update.

The game stores the gem total in localStorage on that browser/device. This is an early playable prototype: one level, simple original canvas artwork, no external libraries, accounts, or paid services.
